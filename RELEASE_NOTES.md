## Fisher Online 4K Fish Textures v0.1.0

First public preview release of the ongoing 4K fish overhaul.

- 34 version-locked bundle patches covering 29 named fish groups
- normal, large, and trophy appearances where the game provides them
- 4096x4096 color maps and upgraded normal/material maps
- UV-preserving repaints with original meshes retained, apart from the verified
  Blue Marlin large-model UV correction
- dependency-free Windows PowerShell installer
- SHA-256 preflight, dated backups, staged replacement, and automatic rollback
- no original Fisher Online bundles included in the download

Read `README.md` inside the archive before installing. Fisher Online must be
closed, and Steam Verify Integrity should be run first so the source bundle
hashes match this release.
