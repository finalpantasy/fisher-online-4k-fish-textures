The table is a representative set retained from the earlier public preview.
The release manifest is the complete, exact inventory: it contains 91
bundle-level entries because several fish use separate normal, large, or
trophy bundles, and records each patch's source, target, and patch hash.

Brook Charr (`Salvelinus fontinalis`) is the correct identity for
`fishs_assets_fishingame_74_palia.bundle`; the older Arctic-char label was
incorrect. Only bundles with a current live SHA-256 that matches a successful
installation journal are included.
